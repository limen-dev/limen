---
title: What is built and what is verified
description: The honest state of every capability, including what has not been tried against real cloud services.
---
Limen is tested thoroughly against **local stand-ins**: Dex for the identity provider, containers for databases and brokers, a local S3 and KMS, a fake Datadog intake. **Nothing has been verified against real AWS, Okta, or Datadog yet.** Each gap below has a "Verify" issue in the [Real-environment verification milestone](https://github.com/limen-dev/limen/milestone/21).

<span class="chip ok">built</span> means it works and is tested locally. <span class="chip warn">unverified</span> means a cloud or vendor-specific path is written but has not met the real service. <span class="chip plan">planned</span> means not built.

## Not claimed

- Anything compared with another product. Limen claims properties you can test.
- Compliance outcomes. Evidence packs help an audit; they are not a certification.
- Anything on the roadmap. The roadmap says what is planned, and so does every page that mentions it.

The source of truth is [design §14](../architecture/design/#14-assumptions-and-open-items) and the [roadmap milestones](https://github.com/limen-dev/limen/milestones).
